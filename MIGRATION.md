# Content migration: inventory and URL map

Working notes for moving docs.artineering.io (Jekyll, `C:\DEV\flair-docs`) and the public Notion docs
(Public / Documentation) into this site. Delete this file once the migration is done.

## Status (2026-11-06)

- **Maya: converted.** 58 pages, generated by `scripts/convert_maya.py` (re-runnable; it replaces
  `src/content/docs/maya` and `src/partials/maya`, and copies referenced media without deleting any).
- **Unreal: converted.** 21 pages plus the Unreal halves of the 2 shared tool pages, written from Notion, with their 50 images
  downloaded to `public/media/unreal/`.
- **Shared sections** hold only what exists in both hosts:
  - `/tools/`: NoiseFX and Style Presets (the shared Qt windows in `flair/shared/`: `nfx_view.py`,
    `presets_view.py`). The Flair Toolbox is a stub in UE (`tbox.py`), so it stays in Maya.
  - `/effects/`: Ambient Occlusion, Atmosphere, Bleeding, Edge Darkening, Lines, Sketch Lines, Pigment
    (matched to the `/Flair/Effects` layers `Flair_AO`, `Flair_Atmosphere_Tint`, `Flair_Bleeding_*`,
    `Flair_Edge_Darkening`, `Flair_Line_Detection/Dilation/Drawing`, `Flair_Line_Sketch`,
    `Flair_Pigment_Density`). Maya-only effects stay inline on the Maya style pages.
  - Each shared page has `Unreal Engine` / `Maya` tabs that follow the host switcher.
- **Before/after sliders** replace the old jQuery twentytwenty sliders (`public/scripts/before-after.js`).
- **Not migrated yet:** Notion "Troubleshooting Dependencies" (Maya; its zip and video live in Notion) and
  the UE setup video on the Notion landing page.

### Known gaps

- Unreal tabs on `/effects/` pages only name the effect layer(s); Notion has no per-effect parameter docs.
- Mermaid diagrams (both Breakdown pages) show as code; they need a Mermaid renderer.
- Headings inside tabs (shared pages) don't appear in "On this page", a Starlight limitation for
  imported content.
- For shared effects, the Maya tab uses the watercolor variant; the warp-specific demo clips of Edge
  Darkening and Pigment are no longer shown.
- Anchors already broken on the old site: `#lightmap` (flair-shader), `#line-light-response` and
  `#sketch-light-response`, `#function-getmayaattrs` and `#function-customimport` (API import-export).
- Pages still use the old site's HTML figures and classes, styled by `src/styles/content.css`. Converting
  them to Markdown images (and `src/assets/` optimization) is a later pass.

## Principles

- **Maya keeps its old structure.** `/flair/<path>/` on docs.artineering.io becomes `/maya/<path>/` here,
  so every old URL has a one-to-one redirect target and in-page links only need a prefix swap.
- **Unreal comes from Notion**, as two groups that mirror the two guides (Artist, Technical Artist).
- **Tutorial videos stay on YouTube** (the `responsive-embed` include). The short looping UI clips
  (`<video autoplay loop>`, 124 of them) are content and are copied with the images.
- **Media mirrors the pages that use it**: `/media/<page path>/<file>`, e.g.
  `/media/maya/styles/library/watercolor/` or `/media/effects/pigment/`. `scripts/organize_media.py`
  moves files and rewrites links (`convert_maya.py` runs it at the end). A file used by several pages
  goes to the shared `/effects/` or `/tools/` page using it, else to the deepest section those pages
  share (`/media/shared/` only across hosts). Only referenced files are copied. Moving images to
  `src/assets/` for Astro's image optimization is a later, separate step.
- **Four Warp demo clips were dropped** (`edge-darkening-*.mp4`, `paper-granulation.mp4`,
  `pigment-density.mp4` in the old site's `media/styles/warp/`): they illustrated shared effects on the
  old Warp page and went with the effect stubs. The originals remain in the old repo.
