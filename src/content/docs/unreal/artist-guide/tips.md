Here are some of the hottest Tips and Best Practices we recommend:

- Use [style presets](/tools/style-presets/) to quickly switch between looks and find a good starting point
- Experiment with different FlairStyle parameters and save presets of interesting results
- Presets are `.json` files, so commit them to version control alongside your project
- If a style does not have the effect you want, then it's time to learn the [Technical Artist Guide](/unreal/technical-artist-guide/) so that you can fully customize Flair for Unreal Engine!
