The technical artist guide to authoring Flair styles with effect layers in Unreal Engine. This documentation builds upon the [Artist Guide](/unreal/artist-guide/), so make sure to review the artist documentation first for better understanding.

:::note[For Artists]
If you're just using Flair to stylize scenes (loading presets, adjusting parameters, NoiseFX), see the [Artist Guide](/unreal/artist-guide/).
:::

## Why a technical artist guide?

Authoring styles can quickly become technical, so we did not want to overwhelm artists with the technicalities of Flair. This guide documents how to build the styles and tools that artists use, by mix-and-matching effects using effect layers, writing your own Post-Process Materials and defining the controls that artists will have available during production.

**Key features:**

- Define a Flair style with Flair Effect Layers
- Create Flair Effect Layers
  - Render Passes
  - Post Process Materials (PPMs)
  - Material parameter collections (MPCs)
  - Exposed/Unexposed Parameters
  - Control Definitions
- Create Flair PPMs

Artists interact with your curated result using style presets, style parameters and art-direction tools such as NoiseFX. You decide what they can touch and how it's presented to them!
