The _NoiseFX_ tool simplifies the procedural control of effects on selected objects. It lives in the **Flair FX** window, opened by clicking on the `NFX` shelf icon.

<figure>
<img src="/media/tools/noisefx/window.png" alt="The NoiseFX tool in Unreal Engine" />
<figcaption>NoiseFX of the Lines style</figcaption>
</figure>

All **material instances** (MIC or MID) containing a _Flair Slab_ (see [Add support for Render Passes](/unreal/artist-guide/getting-started/#add-support-for-render-passes)) support NoiseFX, but the effects available within the NoiseFX tool depend on the loaded style. Plain materials are skipped, so make an instance first. Decals are supported too: select the Decal Actor to art-direct its decal material instance.

To apply NoiseFX, simply select objects and modify the desired slider (materials should contain the Flair Slab). Changes affect all meshes sharing the same material, which is the intended behavior (e.g., "all skin materials get pigmentation noise"). With nothing selected, NoiseFX keeps using your **last** selection.

From top to bottom, these are the different elements of the NoiseFX tool.

### Header

On top, you will find the _NoiseFX header_ and three buttons

- <img src="/media/tools/noisefx/refresh.png" alt="Refresh" class="inline-icon" /> Refresh button to reload the controls and sync the UI.
- <img src="/media/tools/noisefx/bake.png" alt="Bake" class="inline-icon" /> Bake button to bake the positions of the NoiseFX by toggling the `Animated` parameter the assigned materials. If the 3D position is not baked, NoiseFX will "float" in 3D space, instead of moving with animated objects.
- <img src="/media/tools/noisefx/reset-all.png" alt="Reset all" class="inline-icon" /> Reset button, which resets ALL NoiseFX of the selected objects.

### NoiseFX Widgets

Each style has different effects, therefore, the noise widgets (sections) will vary depending on the currently loaded style. Each widget handles a specific effect within the style e.g., _Lighting_, _Pigment turbulence_, _Color bleeding_.

On the left side of each widget, you will always find a generalized term for the behavior of each effect. Right next to it, there will be a sphere icon highlighting that it affects the material.

#### Toggle/reset

To the right of the preview icon, you will find two buttons.

- <img src="/media/tools/noisefx/noisefx-reset.png" alt="Reset" class="inline-icon" /> This button resets the NoiseFX values for that effect, allowing to start anew or completely remove its influence. This button is smaller than the reset _ALL_ NoiseFX button at the top-right of the window.
- <img src="/media/tools/noisefx/toggle.png" alt="Toggle" class="inline-icon" /> This button toggles the NoiseFX on/off to visualize the influence that the noise makes for the style.

#### NoiseFX type

Directly underneath the material icon, there is a combo box widget that gives the ability to change between different noise types.

- **None** - No NoiseFX is applied
- **Simple** - Default simplex noise
- **Cloud** - Fractalized noise resembling the cloud noise in Photoshop
- **Custom** - Your own noise. Define it in `Flair/Content/Materials/_Functions/Flair_NoiseFX_Custom`, which ships with an empty Custom expression to fill in.

When multiple materials are selected and each one contains a different noise type, the combo box widget will be highlighted in red after refreshing the GUI.

#### Modifying noise

Modifying noise is simple, select the object with the materials that you wish to modify and use one of the three relative sliders.

- **Noise** - Modifies the noise amplitude for the specified effect (how strong it is). Keep in mind that noise is composed out of positive and negative values and it acts in both directions.
- **Scale** - Modifies the noise frequency for the specified effect (how big or small the noise is). The frequency is relative to the _World Scale_ parameter in the FlairStyle actor.
- **Phase** - Modifies the phase of the noise to get different patterns at the same scale.
- **Shift** - Shifts the noise towards positive or negative values, accordingly. This is also useful if you want to have more or less of an effect, with or without procedural noises.

### Internal workings

The NoiseFX tool abstracts various material parameters and simplifies the toggling and modifying thereof in the Material Details panel.

![NoiseFX parameters in the Material Details panel](/media/tools/noisefx/material-details.png)

The parameters are found within each material when opening the `~ Flair FX` group in the Material Details.

Style authors use **Control Definitions** within each Flair Effect layer to define which NoiseFX widgets will be available for artists to use. You can learn how to create your own definitions in [Control Definitions](/unreal/technical-artist-guide/effect-layers/control-definitions/).

## Noise widgets
Each style has different effects, therefore, the noise widgets (sections) will vary depending on the currently loaded style. Each widget handles a specific effect/behaviour within the style e.g., _Lighting_, _Pigment turbulence_, _Color bleeding_.

On the left side of each widget, you will always find a generalized term for the behaviour of each effect. Right next to it, there will be a sphere icon that gives a preview of what the effect will do.

### Toggle/reset
To the right of the preview icon, you will find two buttons.

This button resets the NoiseFX values for that effect, allowing to start anew or completely remove its influence. This button is smaller than the reset _ALL_ NoiseFX button at the top-right of the window.

<figure class="float-left">

This button toggles the NoiseFX on/off to visualize the influence that the noise makes for the style.

### NoiseFX type
Directly underneath the preview icon, there is a combo box widget that gives the ability to change between different noise types.

* **None** - No NoiseFX is applied
* **Simple** - Default simplex noise
* **Cloud** - Fractalized noise resembling the cloud noise in Photoshop
* **Custom** - Custom noise, which can be written in glsl `flair/maya/shaders/material/include/noise.glsl` [`customNoise(vec4 v)`].

When multiple materials are selected and each one contains a different noise type, the combo box widget will be highlighted in red.

### Modifying noise
Modifying noise is simple, select the object with the material that you wish to modify and use one of the three relative sliders.

* **Scale** - Modifies the scale of the 3D/2D noise for the specified effect [noise frequency]. The scale will be relative to the [World Scale](/maya/getting-started/globals/#world-scale) global attribute.
* **Noise** - Modifies the contrast (how strong it is) of the noise for the specified effect. Keep in mind that noise is composed out of positive and negative values and the contrast amplifies the noise in both directions [noise amplitude].
* **Phase** - Modifies the phase of the noise to get different patterns at the same scale [noise phase].
* **Shift** - Shifts the noise towards positive or negative values, accordingly [noise shift].

## FAQ
<details>

<summary>Can I change the type of noise that NoiseFX uses?</summary>

Yes, you can write your own noise function for the _Custom_ noise type. However, you will need to modify the material glsl shader code to do so at `flair/maya/shaders/material/include/noise.glsl` [`customNoise(vec4 v)`].
