Styles within Flair are created through shader pipelines that are defined either internally or using the [Flair graph](/maya/styles/library/graph/).
These pipelines are controlled via parameters that are normally exposed as attributes in the [globals node](/maya/getting-started/globals/) of the style.

The documentation herein covers everything there is to know about working with Flair styles.
